## Instrucciones

Cada grupo realizará el recorrido de selección, formulario, revisión, confirmación y consulta con datos ficticios. Registrará únicamente lo que haya observado. Adjuntará evidencias cuando sea posible y diferenciará problemas reproducidos de sugerencias.

Escala propuesta para esta actividad: 0 sin problema observado, 1 menor, 2 moderado, 3 grave y 4 bloqueante. Marcar NE cuando una comprobación no se haya ejecutado. La escala es una propuesta del proyecto.
